Code Layer

在 Storybook 上，像用 Figma 一樣調整樣式。

選取元件，點一下數值，換成另一個 design token。確定之後按一個按鈕，就寫進真實的程式碼。

開始旅程 認識介面
  1. 1選取打開工具列的 Code Layer，點一下畫面上的元件。
  2. 2換 token在檢視器點數值，挑另一個 token，畫面立刻預覽。
  3. 3套用到檔案按下去才寫入。寫完自動檢查，也可以還原。

按下「套用到檔案」之前，你看到的都只是預覽，檔案不會改變。

跟著旅程走一遍。

    常見問題。
    
    
    
      
    
        我在檢視器上改了，檔案就改了嗎？
        
    還沒有。挑了 token 之後只是暫存，畫面是預覽。檢視器底部會一直顯示「預覽中 · n 項變更尚未寫入檔案」，直到你按「套用到檔案」或「捨棄」。
    
      
    
      
    
        套用需要經過 AI 嗎？
        
    不需要。「套用到檔案」是工具自己把 token 換好、寫進檔案、檢查畫面，不會用到 AI。只有你主動交給 AI 時才會用到：報告裡出現「文件待同步」、你想改有鎖頭的列，或你按了「請 AI 修改」。
    
      
    
      
    
        看不到 AI 按鈕，或按鈕是灰的？
        
    「請 AI 修改」預設是關的，要兩件事都做了才會打開：專案的 Code Layer 設定加上 "agent": { "enabled": true }（這是專案的決定，改完要重新啟動 Storybook），而且你的電腦執行過啟用腳本（這是你這台電腦的決定）。
    還沒打開時，標題列的 ✦ 是灰的，滑鼠停上去會說明原因，例如「AI 修改目前不能用：這個專案還沒有啟用 AI 修改。」；選取框的標籤上也不會有「AI」。想用的話，請你的 AI 助理說明並幫你啟用：它會先講清楚費用、每次都要你允許這些事，你同意了才會設定。
    
      
    
      
    
        要花錢嗎？
        
    會。每次請求都由你電腦上的 AI 命令列工具（預設是 Claude Code）執行，費用算在你自己的帳號，也需要一些時間。工具不會自動重試。
    只用檢視器換 token、按「套用到檔案」，完全不會用到 AI，也不會花錢。
    
      
    
      
    
        為什麼要在瀏覽器外按允許？
        
    因為頁面上的程式（包括 story 裡的程式碼）也能送出請求。允許這一步放在瀏覽器外，只有坐在電腦前的你按得到，而且每一次都要按。
    macOS 會跳出系統確認視窗，寫著專案、元素、要用的工具、AI 可以改的檔案和你的請求；預設的按鈕是「拒絕」，60 秒沒有回應就當作拒絕。沒辦法顯示視窗時，執行 Storybook 的終端機會印出六位數確認碼，把它輸入在對話框裡；打錯三次就作廢，3 分鐘後失效。
    
      
    
      
    
        AI 會改到哪些檔？
        
    只會改三種既有的檔案：可以寫入的 token 檔、元件資料夾裡的檔案、元件規格檔。確認視窗會列出確切的範圍。
    AI 在專案的複本上工作，做完之後工具逐一檢查。只要有一項不合規定，整個結果都不採用，專案完全不變：
      
          
    • 新增或刪除檔案，或改到範圍以外的檔案。
      • 
          
    • 直接改 token 的同步複本，或新增、刪除 token。
      • 
          
    • 改完的 CSS 不是有效的寫法。
      • 
          
    • AI 工作期間，你自己也改了同一個檔。
      • 
        
    通過檢查的修改會像一次「套用到檔案」一樣寫入，token 的同步複本由工具一起寫；按結果上的「還原」可以整份放回去。
    
      
    
      
    
        AI 問我問題怎麼辦？
        
    結果會顯示「AI 需要你決定」。按「回答」，對話框的標題變成「回答 AI 的問題」，下面照原文顯示它的問題。打你的回答，按「送出回答」：回答是一筆新的請求，一樣要你在瀏覽器外允許。
    回答不能放寬規則。例如 AI 問要不要新增 token，你回答「可以」，結果還是會因為新增了 token 而不被採用；需要新 token 時，請先由人新增，再請 AI 換上去。
    
      
    
      
    
        會寫到哪些檔案？
        
    依修改範圍而定：token 檔（和它的同步複本）、元件的樣式表、元件規格表裡對應的那一列。寫完會自動重新產生設計系統的文件頁。
    想看確切的檔案和行號，打開標題列的 <> 開發者資訊。
    
      
    
      
    
        改壞了怎麼辦？
        
    還沒套用：按「捨棄」，或按每一筆右邊的 ✕。已經套用：按報告上的「還原」。AI 的修改也一樣，按 AI 結果上的「還原」。
    寫入之前工具會先跑專案的檢查，沒通過就不會動任何檔案。每次寫入都有備份和紀錄。
    
      
    
      
    
        可以一次改很多項嗎？
        
    可以。想改的都先挑好，最後按一次「套用到檔案」。這一批會一起成功，或一起不寫入，不會只寫一半。
    
      
    
      
    
        我改了一個元件，別的頁面也會變嗎？
        
    會。你改的是 token 或樣式規則，所有用到它的地方都會跟著變。工具只在目前這一頁檢查畫面，浮層和報告會告訴你影響幾個元件。
    
      
    
      
    
        排列的選項為什麼不是 token？改了會寫到哪裡？
        
    方向、對齊、分布、換行的值是 CSS 的關鍵字（例如 column、center），不是數值或顏色，所以沒有 token。工具會直接改元件樣式表：這個屬性已經有寫就改那一行，還沒寫就在宣告 display 的那條規則最後新增一行。浮層最下面會寫出是哪條規則。
    選項是固定的幾個，不能輸入別的值。數值、顏色和字級仍然只能用 token。
    
      
    
      
    
        為什麼有些元素的方向、對齊是鎖住的？
        
    這四個設定只對 flex 容器有作用。選到的元素不是 flex 容器時，它們沒有效果，所以鎖住。另外，樣式表裡用 place-items 這類簡寫設定、或值不是單一關鍵字時，工具不會去改，也會鎖住並說明原因。
    
      
    
      
    
        有哪些事還不能做？
        
      
          
    • 改顯示方式（display）、grid 的排列、子元素的順序，或用拖曳調整大小與位置。flex 容器的方向、對齊、分布、換行可以改。
      • 
          
    • 改寫死的數值本身（例如把 88px 改成 96px），或新增一個原本沒有的 token。寫死的值可以換成既有的 token，但只改那一條宣告。
      • 
          
    • 選取或修改 ::before／::after 這類裝飾，以及滑鼠移上去、聚焦時才出現的樣式。
      • 
          
    • 只改畫面上的某一顆元件，而不影響同款的其他顆。
      • 
        
    這些可以交給 AI：專案啟用了「請 AI 修改」時，直接在檢視器旁請它改；也可以用「複製參照」貼給 AI 對話。「請 AI 修改」只能修改既有的檔案，不能新增 token 或檔案。
    
      
    
      
    
        寫死的值換成 token，畫面會變嗎？
        
    挑「數值相同」那一組的 token，畫面不變，結果會寫「已寫入並驗證，外觀不變」。挑別的 token，就變成那個 token 的值。
    「數值相同」只對目前的主題成立：專案有深色主題時，同一個 token 在另一個主題可能是別的值。換上去之後，這個屬性就會跟著 token 變。
    工具只改那一條宣告，不會動元件 token 或全域 token，所以浮層裡沒有修改範圍可以選。按「還原」會把原本寫死的數值放回去。
    
      
    
      
    
        工具列的 Code Layer 亮著，但選不到東西？
        
    工具暫停了，滑鼠停在按鈕上會顯示原因。常見的是：目前在 Docs 頁、Figma export 開著、Prototype Inspector 不在 Story 模式，或這個 story 正在顯示錯誤畫面。回到一般的 story 就會恢復。
    
      
    
      
    
        出現「請重新整理頁面」是什麼意思？
        
    Storybook 重新啟動過，而且工具更新了。重新整理一次就會用到新版。只是重新啟動、沒有更新的話，頁面會自己恢復連線，不用處理。
    
      
    
      
    
        介面為什麼是英文？
        
    介面跟著瀏覽器的語言走。想固定成中文，請管理專案的人在 Code Layer 的專案設定加上 "locale": "zh-Hant"。
    
      
    
      
    
        檢視器擋到我要看的地方？
        
    拖曳標題列移到別處，或按右上角的箭頭收合成一條。還沒拖過之前，它會自己停在不擋住元件的那一側。
